Project Overview

Not a club setup. A production system.

For the 2026 DMC World DJ Championships programme, the aim is to provide a reliable technical production model across multiple Camden events. The system covers DJ booth infrastructure, live audio, capture, broadcast preparation, recording, streaming support and crew delivery.

The production model is designed so every DJ performs under consistent technical conditions, every changeover can be handled quickly, and every important signal path is protected, recorded and ready for broadcast or post-production.

Operating Principles

Four rules define the system.

Isolation

Each booth is treated as its own technical unit so one fault does not spread across FOH, recording or broadcast.

Parallel Distribution

FOH, broadcast, recording and backup paths run at the same time rather than relying on mid-show repatching.

Controlled Changeover

The target workflow supports clean transitions in around 75–90 seconds where fast rotation is required.

Continuity by Design

UPS power, isolated splits, tested cable paths and defined crew roles are built into the base design.

DJ Booth Architecture

Three-position booth rotation.

A

Live Booth

The active booth currently in use by the performer.

B

On-Deck Booth

Prepared, powered, checked and ready to move into the live position.

C

Standby Booth

The next booth in preparation, allowing the crew to work ahead of the performance order.

The preferred booth model uses mains power supported by UPS and a single Cat5/Cat6 EtherCON-style connection carrying balanced audio infrastructure back to the central breakout point.

Streaming & Broadcast

Streaming must be treated as production-critical.

Where livestreaming is confirmed, the safest model is a dedicated stream operator, primary and backup internet paths, local programme recording, platform health monitoring and clear written expectations around quality, platforms, destinations and failure tolerance.
