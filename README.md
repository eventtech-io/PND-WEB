# PND GitHub Pages

Static GitHub Pages-ready site for Party Never Dies.

## Pages
- `index.html` — landing page
- `founders.html` — founders page linking to Dbase and Event Tech Research
- `dbase.html` — Dbase founder profile
- `event-tech-research.html` — Event Tech Research founder profile

## Deploy on GitHub Pages
1. Upload this folder to a GitHub repository.
2. Go to Settings → Pages.
3. Set Source to `Deploy from a branch`.
4. Select the branch and `/root` folder.
5. Save.

The `.nojekyll` file is included so GitHub Pages serves the static assets directly.
